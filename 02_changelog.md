## [1.0.0-MVP] — 2026-11-11
### Добавлено
- Интерактивный веб-интерфейс в эстетике Haute Horlogerie:
  - Canvas-симуляция швейцарского анкерного спуска (Swiss lever escapement) с кинематикой анкерного колеса, вилки с рубиновыми палетами, спирали баланса и регулятором частоты колебаний (18,000 / 21,600 / 28,800 / 36,000 vph).
  - Сплит-слайдер макро-реставрации («До» — коррозия и осыпание радия / «После» — зеркальная полировка англажа и эмалевый циферблат).
  - Форма онлайн-оценки по фото часов с мгновенным расчетом ориентировочного диапазона работ.
  - Портал проверки статуса заказа по трек-номеру (CR-8492) с 6 стадиями реставрации.
  - FastAPI REST API эндпоинты: `/api/showcase-models`, `/api/track-order/{id}`, `/api/appraisal-request`, `/health`.
- Полнофункциональный Telegram-бот на Aiogram 3.x:
  - FSM-диагностика с приемом фото часов и описанием дефектов.
  - Автоматическая предварительная смета часовщика.
  - Модуль отслеживания статуса заказа по номеру (`/track CR-8492`).
  - Пересылка заявок в аккаунт куратора `@Idrisov_prod`.
- Комплекс юнит- и смоук-тестов (API, расчет сметы, трекинг, бот).
