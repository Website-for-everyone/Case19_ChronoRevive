# ChronoRevive — Ателье реставрации винтажных часов

Музейная реставрация исторических калибров, восстановление эмалевых циферблатов и ювелирная полировка швейцарской механики.

---

## 🌟 Ключевой функционал

### 1. Веб-приложение (Haute Horlogerie UI)
- **Анимированный швейцарский анкерный спуск:** Интерактивная физическая симуляция анкерного колеса, палетной вилки и балансового колеса со спиралью Breguet. Переключение частоты полуколебаний (18,000, 21,600, 28,800, 36,000 vph) и аудио-эффект тиканья механизма.
- **Макро-слайдер реставрации («До / После»):** Наглядное сравнение корродированного винтажного механизма 1950-х годов с результатом после ультразвуковой очистки, воронения винтов и ручной полировки англажа.
- **Форма онлайн-оценки по фото:** Отправка фотографий механизма и циферблата с мгновенной оценкой диапазона стоимости и сроков.
- **Портал отслеживания заказа по ID (например, `CR-8492`):**
  1. Полная разборка и дефектовка
  2. Ультразвуковая очистка камней и трибов
  3. Изготовление утраченных цапф и полировка осей
  4. Восстановление циферблата и люма
  5. Юстировка точности на приборе Witschi Chronocomparator
  6. Тестирование герметичности в барокамере

### 2. Telegram-бот (Aiogram 3.x)
- Прием фотографий часов и калибра для удаленной дефектовки мастером.
- Экспресс-калькулятор стоимости реставрации.
- Отслеживание текущей стадии работ по номеру заказа (`/track CR-8492`).
- Пересылка входящих заявок в аккаунт куратора `@Idrisov_prod`.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-сервера
```bash
python web/app.py
```
Адрес: `http://localhost:3019`

### 3. Запуск Telegram-бота
```bash
python bot/bot.py
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
